
# Hand Survivor 🎮

A real-time hand-tracking survival game controlled using your webcam.

Move your hand to control the player, avoid incoming obstacles, survive as long as possible, and use gestures to activate special abilities.

## 🎮 Controls

- 👊 **Fist** — Start the game / activate Super Power
- ✋ **Open Hand** — Pause / Resume
- ⌨️ **P** — Pause / Resume
- ⌨️ **R** — Restart after Game Over
- ⌨️ **Q** — Quit

## ✨ Features

- Real-time hand tracking
- 3-life survival system
- Increasing game difficulty
- Multiple obstacle types
- Waves and scoring
- Combo system
- Power-ups
- Fist Super Power
- Pause and resume system
- High score tracking
- Game-over and restart system

## 🛠️ Technologies

- Python
- OpenCV
- MediaPipe
- MediaPipe Hand Landmarker

## 🚀 How to Run

### 1. Install the required packages

```bash
pip install mediapipe opencv-python
````

### 2. Make sure these files are in the same folder

```text
Hand-Survivor/
├── hand_game.py
└── hand_landmarker.task
```

### 3. Run the game

```bash
python hand_game.py
```

A webcam is required to play.

## 📌 Model

This project uses the MediaPipe Hand Landmarker model for real-time hand tracking.
